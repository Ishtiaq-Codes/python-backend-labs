# AttendanceChain — Blockchain Attendance Verification System

AttendanceChain is a beginner-friendly but professional full-stack Web3 application demonstrating how blockchain technology can be used for immutable and tamper-resistant record-keeping. 

It allows authorized teachers to mark student attendance directly on the Ethereum blockchain, while students can freely search and verify their attendance history without needing an account or wallet.

## Features
- **Smart Contract Security**: Only the authorized contract owner (Teacher) can write attendance records to the blockchain.
- **Immutable Records**: Once attendance is marked, it cannot be altered or deleted.
- **Gasless Verification**: Students do not need a wallet to view records. The frontend reads directly from the blockchain node.
- **Web3 Wallet Integration**: Connects to MetaMask using `ethers.js` v6.
- **Modern UI**: Clean, responsive, and intuitive interface built with React and Tailwind CSS.

## Architecture

The repository is structured as a monorepo with two primary components:
- **`blockchain/`**: The Hardhat development environment containing the Solidity smart contract `AttendanceChain.sol`, deployment scripts, and unit tests.
- **`frontend/`**: The React-based Web3 dashboard built with Vite, Tailwind CSS, and `ethers.js` v6.

## Technology Stack
- **Smart Contracts**: Solidity ^0.8.24, OpenZeppelin Ownable, Hardhat
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, lucide-react
- **Web3 Integration**: ethers.js v6, MetaMask Provider

## Installation & Setup

### Prerequisites
- Node.js v18+
- MetaMask extension installed in your browser

### 1. Blockchain Setup

Navigate to the blockchain directory and install dependencies:
```bash
cd blockchain
npm install
```

Compile the smart contracts:
```bash
npx hardhat compile
```

Run the test suite to ensure everything is working:
```bash
npx hardhat test
```

### 2. Frontend Setup

Navigate to the frontend directory and install dependencies:
```bash
cd frontend
npm install
```

## Running Locally

To run the full stack locally for development and testing:

1. **Start the local Hardhat node:**
   ```bash
   cd blockchain
   npx hardhat node
   ```

2. **Deploy the contract locally:**
   In a new terminal window, run:
   ```bash
   cd blockchain
   npx hardhat run scripts/deploy.js --network localhost
   ```

3. **Start the Frontend Development Server:**
   ```bash
   cd frontend
   npm run dev
   ```

4. **Connect MetaMask:**
   - Add the Localhost network to MetaMask (RPC URL: `http://127.0.0.1:8545`, Chain ID: `31337`).
   - Import the first private key generated by Hardhat into MetaMask to act as the Teacher (Contract Owner).

## Deploying to Sepolia Testnet

1. Create a `.env` file in the `blockchain` directory based on `.env.example`:
   ```env
   ALCHEMY_API_KEY="your-alchemy-api-key"
   SEPOLIA_PRIVATE_KEY="your-wallet-private-key"
   ```

2. Deploy to Sepolia:
   ```bash
   npx hardhat run scripts/deploy.js --network sepolia
   ```
