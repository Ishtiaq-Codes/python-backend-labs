# TokenForge — ERC20 Token Management Web3 Dashboard

TokenForge is a complete, production-ready Web3 application that allows users to interact with a custom ERC20 smart contract. Built as a full-stack blockchain project, it demonstrates best practices in smart contract development using Solidity, and modern Web3 frontend integration using React, TypeScript, and ethers.js.

## Architecture

![Architecture](https://via.placeholder.com/800x400?text=TokenForge+Architecture)

The repository is structured as a monorepo with two primary components:
- **`blockchain/`**: The Hardhat development environment containing the Solidity smart contracts, test suites, and deployment scripts.
- **`frontend/`**: The React-based Web3 dashboard built with Vite, Tailwind CSS, and `ethers.js` v6 for interacting with the deployed contract via MetaMask.

## Features
- **ERC20 Implementation**: Standard ERC20 token named `TokenForge Token` (TFT).
- **Minting Mechanism**: Only the contract owner can mint new tokens, secured by OpenZeppelin's `Ownable`.
- **Burning Mechanism**: Any user can burn their own tokens to reduce the total supply.
- **Pausable Transfers**: Emergency stop mechanism controlled by the owner.
- **Web3 Dashboard**: Modern SaaS-style UI to view balances, transfer tokens, mint, burn, and track recent transactions in real-time.

## Technology Stack

- **Smart Contracts**: Solidity ^0.8.24, OpenZeppelin Contracts, Hardhat
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, lucide-react
- **Web3 Integration**: ethers.js v6, MetaMask Provider

## Installation & Setup

### Prerequisites
- Node.js v18+
- MetaMask extension installed in your browser

### 1. Blockchain Setup

Navigate to the blockchain directory and install dependencies:
```bash
cd blockchain
npm install
```

Compile the smart contracts:
```bash
npx hardhat compile
```

Run the test suite to ensure everything is working:
```bash
npx hardhat test
```

### 2. Frontend Setup

Navigate to the frontend directory and install dependencies:
```bash
cd frontend
npm install
```

## Running Locally

To run the full stack locally for development and testing:

1. **Start the local Hardhat node:**
   In the `blockchain` directory:
   ```bash
   npx hardhat node
   ```
   *This will start a local Ethereum network and give you 20 test accounts.*

2. **Deploy the contract locally:**
   In a new terminal window, run:
   ```bash
   cd blockchain
   npx hardhat run scripts/deploy.js --network localhost
   ```
   *The script automatically exports the contract ABI and address to the frontend `src/contracts` directory.*

3. **Start the Frontend Development Server:**
   ```bash
   cd frontend
   npm run dev
   ```

4. **Connect MetaMask:**
   - Add the Localhost network to MetaMask (RPC URL: `http://127.0.0.1:8545`, Chain ID: `31337`).
   - Import one of the private keys generated by Hardhat into MetaMask to act as the contract owner.

## Deploying to Sepolia Testnet

1. Create a `.env` file in the `blockchain` directory based on `.env.example`:
   ```env
   ALCHEMY_API_KEY="your-alchemy-api-key"
   SEPOLIA_PRIVATE_KEY="your-wallet-private-key"
   ```

2. Update `hardhat.config.js` to include the Sepolia network configuration.

3. Deploy to Sepolia:
   ```bash
   npx hardhat run scripts/deploy.js --network sepolia
   ```
